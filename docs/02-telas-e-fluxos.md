# Book Soccer — Mapa de telas e fluxos (rascunho 1)

Aplicativo de celular. Navegação por barra inferior, diferente em cada perfil.

## Telas comuns (entrada)

1. Abertura
2. Boas-vindas
3. Escolha do perfil (scout, agente, atleta)
4. Login / criar conta

## Scout

Barra inferior: **Início · Buscar · Cadastrar (+) · Listas · Perfil**

| Tela | Conteúdo |
|---|---|
| Início | Resumo: atletas em acompanhamento, últimas avaliações, pedidos pendentes |
| Buscar | Campo de busca e botão de filtros |
| Filtros | Idade, posição, pé, altura, atributos mínimos, região, categoria |
| Resultados | Cards de atletas com foto, posição, idade e nota geral |
| Perfil do atleta | Abas: Resumo · Avaliações · Vídeos · Histórico. Ações: avaliar, favoritar, solicitar contato |
| Nova avaliação | 1) Jogo observado → 2) Notas dos atributos (1 a 10) → 3) Observações → Salvar |
| Relatório | Por observação ou consolidado, com evolução e botão de compartilhar |
| Comparar | Até 3 atletas lado a lado |
| Listas | Minhas listas e etapas de acompanhamento |
| Novo atleta | Formulário. Se menor: responsável e documento de autorização |

## Agente

Barra inferior: **Início · Carteira · Buscar · Pedidos · Perfil**

| Tela | Conteúdo |
|---|---|
| Início | Resumo da carteira e pedidos novos |
| Carteira | Atletas representados |
| Compartilhar perfil | Enviar a vitrine do atleta a um scout ou clube |
| Pedidos de contato | Lista com aceitar ou recusar |
| Buscar | Mesma busca do scout |

## Atleta

Barra inferior: **Meu perfil · Vídeos · Quem viu · Conta**

| Tela | Conteúdo |
|---|---|
| Meu perfil | Dados, posição, histórico e status de verificação |
| Editar perfil | Formulário de dados |
| Vídeos | Subir e organizar lances |
| Quem viu | Visualizações e pedidos de contato recebidos |
| Verificação | Passo a passo: dados → documento → (menor) responsável e autorização → em análise → verificado |

## Fluxos principais (candidatos à demonstração)

1. **Scout avalia um atleta em um jogo:** Início → Cadastrar → novo atleta → nova avaliação → relatório.
2. **Scout busca e compara:** Buscar → filtros → resultados → perfil → adicionar à lista → comparar.
3. **Atleta se cadastra:** escolha do perfil → dados e data de nascimento → (se tiver menos de 18 anos) responsável e documento de autorização → em análise → verificado.
4. **Agente recebe e responde contato:** pedidos → detalhe → aceitar → compartilhar perfil → scout recebe a notificação.
5. **Scout cria conta e é verificado:** escolha do perfil → vínculo com o clube e documentos → em análise → busca com menores ocultos → aprovação → menores liberados.
